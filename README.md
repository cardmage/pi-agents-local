A [Pi](https://github.com/earendil-works/pi) extension. When Pi adds `AGENTS.md` to the context, it also adds the `AGENTS.local.md` in the same folder.

- `AGENTS.md`: team/project instructions
- `AGENTS.local.md`: your own additional instructions

## Install

```sh
pi install git:github.com/cardmage/pi-agents-local
```

To try it for one run without installing:

```sh
pi -e git:github.com/cardmage/pi-agents-local
```

Checked with Pi 1.5.2.

## Behavior

- For every context file Pi loaded (`AGENTS.md`, `AGENTS.override.md`, `CLAUDE.md`), the `AGENTS.local.md` in the same folder is added right after it. This applies to the agent directory (`~/.pi/agent`), the working directory, and its parent directories.
- If Pi did not load a context file from a folder, the `AGENTS.local.md` there is not added either. So it is left out in a folder that has `AGENTS.local.md` but no `AGENTS.md`, when Pi runs with `--no-context-files`, and when another extension removes the context files.
- Like `AGENTS.md`, it is read once per session. Run `/reload` or start a new session to pick up edits.
- `/agents-local` shows the files that were added.

## Known issues

### Foreground pi-subagents children do not get `AGENTS.local.md`

[pi-subagents](https://github.com/nicobailon/pi-subagents) runs a child in the background by default, and there this extension works: `AGENTS.local.md` is added when the child inherits the project context and left out when it does not.

A foreground child (`async: false`) runs inside the parent Pi process, and pi-subagents does not load your installed extensions into it. So it gets `AGENTS.md` (Pi loads that itself) but not `AGENTS.local.md`.

To load this extension in foreground children too, add its installed path to `~/.pi/agent/settings.json`:

```json
{
  "subagents": {
    "defaultSubagentOnlyExtensions": ["~/.pi/agent/git/github.com/cardmage/pi-agents-local"]
  }
}
```

An agent that sets its own `subagentOnlyExtensions` does not use this default; add the path there as well. Checked with pi-subagents 0.89.1.

### Not listed in Pi's startup header

Pi's startup header lists only the context files Pi loaded itself. Use `/agents-local` to see the `AGENTS.local.md` files.

## Tests

```sh
npm test
```

No dependencies to install (Node 22.18 or later). `test/e2e.test.ts` runs the installed `pi` CLI with a temporary agent directory and a local mock server, and checks the system prompt of the requests it sends. It does not touch your Pi configuration or call a real model, and is skipped when `pi` is not installed.
